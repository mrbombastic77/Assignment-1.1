Explanatory Paragraph
When a user types a URL into a web browser (the client), the browser first sends a domain name lookup request to resolve the URL into an IP address. Once the IP address is found, the client initiates a request-response cycle by sending a secure HTTP/HTTPS request to the server housing the website. HTTP (HyperText Transfer Protocol) is the fundamental protocol used to transmit data over the web, whereas HTTPS (HyperText Transfer Protocol Secure) encrypts this data using SSL/TLS to ensure safety and privacy. Upon receiving the request, the server processes it—often communicating with a database to retrieve or store dynamic data—and sends back an HTTP response containing HTML, CSS, JavaScript, and media files. The browser then renders these components on the screen. Depending on the architecture, a static website serves pre-built, identical files directly to every user without backend processing or database queries, whereas a dynamic website generates content in real time based on user interactions, database entries, or personalized input.
